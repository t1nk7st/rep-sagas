# Catálogo de sagas cinematográficas
Este repositorio contiene información sobre diferentes sagas de películas: Star Wars, Harry Potter y El Señor de los Anillos.
Cada saga está organizada en una carpeta con dos archivos de texto: un prólogo que presenta la historia y una lista con sus películas.
El objetivo de esta práctica es aprender a utilizar Git y GitHub para controlar versiones, registrar cambios mediante commits y sincronizar un repositorio local con uno remoto.
El contenido se utilizará como base para un futuro catálogo web de películas.
